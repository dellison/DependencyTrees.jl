Treebanks

A Treebank is a corpus of dependency-annotated sentences in one or more files.

Missing docstring.

Missing docstring for Treebank. Check Documenter's build log for details.

Iterating over a treebank reads sentences one at a time:

treebank = Treebank("data/news.conll", conllu)

for tree in treebank
    # ...
end

tree = first(treebank)

# output
┌────────────── ROOT
│           ┌─► Economic
│        ┌─►└── news
└─►┌──┌──└───── had
   │  │     ┌─► little
   │  └─►┌──└── effect
   │  ┌──└────► on
   │  │     ┌─► financial
   │  └────►└── markets
   └──────────► .
